# 🧠 NexusSentiment

### LLM-Powered Semantic Analysis Engine

NexusSentiment is a modern React-based semantic and sentiment analysis interface designed to analyze text and transform it into meaningful insights such as **sentiment, emotional vectors, extracted entities, and processing telemetry**.

The application provides a futuristic, interactive dashboard where users can enter a paragraph or document and run an analysis pipeline that visually presents the generated results.

---

## ✨ Features

### 📝 Text Analysis

* Analyze paragraphs or text input
* Real-time character and word count
* One-click semantic analysis
* Reset analysis results and start a new analysis

### 📊 Sentiment Analysis

The application generates a primary sentiment score and classifies the input as:

* 🟢 Positive
* 🟡 Neutral
* 🔴 Negative

The sentiment score is displayed as an animated percentage with a visual progress indicator.

### 🎭 Emotional Vectors

NexusSentiment analyzes multiple emotional dimensions:

* **Joy**
* **Analytical**
* **Urgency**
* **Confidence**

Each dimension is represented using a dynamic percentage-based visualization.

### 🧬 Entity Extraction

The application identifies and displays relevant technical entities such as:

* Neural Network
* Optimization
* LLM
* React
* UX Design
* Data Pipeline
* API
* TensorFlow
* Python
* Cloud

These are presented as interactive visual tags within the results dashboard.

### 🖥️ Runtime Processing Logs

The interface includes a terminal-style runtime panel that visually represents the analysis pipeline, including:

1. Input initialization
2. VRAM allocation
3. Tokenization
4. Semantic embedding mapping
5. Transformer attention processing
6. Sentiment distribution
7. Named Entity Recognition
8. Final result generation

This gives the application a developer-oriented, AI-inference dashboard experience.

### ⚡ Processing Telemetry

After analysis, the application displays simulated processing metrics including:

* GPU Utilization
* Inference Latency
* Tokens Processed
* Model Sync Status

## 🧠 How It Works

The application follows a simple analysis workflow:

```text
User Input
    ↓
Text Processing
    ↓
Semantic Analysis
    ↓
Sentiment Calculation
    ↓
Emotional Vector Analysis
    ↓
Entity Extraction
    ↓
Telemetry Generation
    ↓
Interactive Results Dashboard
```

When the user starts an analysis, the interface displays a simulated processing sequence before presenting the final analysis results.

## 🔍 Core Analysis Logic

The current implementation generates analysis results dynamically from the supplied text.

The sentiment score is derived from the input length and then mapped to Positive, Neutral, or Negative categories. Emotional-vector values are also calculated from characteristics of the input, while entities are selected from a predefined technical entity collection.

**Important:** This means the current version is best described as a **semantic-analysis UI/prototype** rather than a production NLP model. The runtime interface presents an AI/LLM-style processing pipeline, but the uploaded code does not contain an actual transformer/LLM inference implementation. This distinction is important when presenting the project professionally.

## 🎯 Project Objective

The goal of NexusSentiment is to create an engaging interface for exploring how natural-language input can be transformed into structured semantic insights.

Instead of presenting analysis as plain text, the application visualizes:

**Sentiment + Emotion + Entities + Processing Metrics**

in a single interactive dashboard.
